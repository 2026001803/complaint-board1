# 🎮 STEAM 소통 신문고 (1:1 대화형 익명 불만·건의 플랫폼)

Steam(스팀) 게이밍 플랫폼 스타일의 감각적인 다크 테마를 바탕으로, 신원 노출 걱정 없이 자유롭게 의견과 불만을 등록하고 담당 부서와 **1:1 대화형(Multi-turn Dialogue)**으로 소통하는 웹 애플리케이션입니다.

---

## 🌟 주요 핵심 기능

### 1. 🔍 [내 불만 바로 조회] 상단 전용 메뉴 (`/track`)
- 상단 헤더에 스팀 시그니처 그린 액션 버튼 스타일로 강조 배치
- **접수 번호(예: `CMP-202611-1001`)**와 **비밀번호(PIN)**를 입력하여 본인의 대화 스레드로 즉시 이동
- 최근 브라우저에서 접수한 내역을 로컬 스토리지에 자동 저장하여 원클릭 빠른 조회 지원

### 2. 💬 단답형을 탈피한 대화형 스레드 (채팅/타임라인 UI)
- 1회성 Q&A가 아닌, **익명 사용자 $\leftrightarrow$ 담당 관리자 간의 지속적인 소통** 지원
- **사용자**: 최초 불만 제기 후, 담당자의 요청에 따른 추가 소명, 정황 설명, 추가 질의 가능
- **관리자**: 공식 답변 등록, 추가 확인 요청(`NEED_INFO`), 진행 상태 실시간 변경(`접수 대기` $\rightarrow$ `처리 중` $\rightarrow$ `추가 확인 요청` $\rightarrow$ `답변 완료` $\rightarrow$ `해결 종결`)

### 3. 🛡️ 철저한 익명성 및 비밀글 보안
- IP 주소, 실명, 연락처 등 개인 식별 정보를 일체 수집하지 않음
- 작성 시 설정한 4자리 이상의 비밀번호(PIN)는 `bcrypt`로 암호화 저장
- **비밀글 설정 기능**: 목록에서 제목이 마스킹 처리되며, 작성자 본인(PIN 인증)과 관리자만 열람 가능

### 4. 📊 STEAMWORKS 관리자 대시보드 (`/admin`)
- 전체 / 접수 대기 / 처리 중 / 추가 확인 요청 / 답변 및 종결 상태별 KPI 현황 통계
- 카테고리별 필터 및 검색 기능
- 공식 답변 표준 템플릿(현장 점검 안내, 추가 정보 요청, 조치 완료 등) 지원
- 상태 변경 이력(Audit Log) 자동 기록

---

## 🛠️ 기술 스택

- **프레임워크**: Next.js 15 (App Router, React 19, TypeScript)
- **스타일링**: Tailwind CSS v4, PostCSS, Lucide Icons
- **데이터베이스 & ORM**: SQLite, Prisma ORM
- **보안 및 인증**: bcryptjs (PIN 해싱), jose (관리자 세션 JWT)

## 🚀 설치 및 실행 방법

### 1. 의존성 설치
```bash
npm install
```

### 2. 환경 변수 설정
`.env.example` 파일을 복사하여 `.env` 파일을 생성합니다:
```bash
cp .env.example .env
```

### 3. 데이터베이스 생성 및 시드 데이터 주입
```bash
npx prisma db push
node prisma/seed.mjs
```

### 4. 개발 서버 실행
```bash
npm run dev
```
브라우저에서 `http://localhost:3000`으로 접속합니다.

## 🔑 기본 테스트 계정 및 데모 데이터

### 1. 관리자 계정
- **접속 URL**: `/admin/login` (상단 헤더의 `[관리자]` 메뉴)
- **아이디**: `admin`
- **비밀번호**: `admin1234!`
- **부서**: 고객소통센터

### 2. 데모 불만 접수건 (비밀번호: `1234`)
- `CMP-202611-1001` (공개글): 사용자 제보 $\rightarrow$ 시설팀 추가 확인 $\rightarrow$ 사용자 피드백 $\rightarrow$ 최종 조치 완료까지 4단계 대화가 이어진 샘플
- `CMP-202611-1002` (비밀글): '내 불만 바로 조회' 창구에서 번호와 비밀번호(`1234`)를 입력하여 잠금 해제 및 대화 확인 가능
